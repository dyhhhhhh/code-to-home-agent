# Hardware Adaptation

本文描述传统家电如何改造成 home agent 可接入的家庭智能节点。

核心原则：

> 不让 AI 直接接触危险负载。给家电增加一个安全、隔离、可回读、可接管的代理层。

## 错误方向

```text
LLM → 继电器 → 市电负载
```

这种方式缺少权限、安规、状态验证和人工接管，尤其不适合门锁、燃气、厨房加热设备、配电箱、热水器和医疗设备。

## 推荐方向

```text
LLM
  ↓
行动请求
  ↓
权限和风险策略
  ↓
本地安全 MCU / 设备代理
  ↓
隔离控制接口
  ↓
家电原控制板
  ↓
状态回读和传感器验证
```

AI 只负责提出请求。安全层决定是否执行。

## 设备代理模块

一个理想的 AI appliance adapter 应包含：

```text
低压 MCU：ESP32、STM32、RISC-V 等。
安全 MCU：独立看门狗和硬规则。
通信：Matter、Thread、Zigbee、Wi-Fi LAN、Ethernet、RS485。
输入：电流、温度、门磁、振动、光照、人体存在、水浸、烟雾、燃气。
输出：红外、继电器、干接点、GPIO、PWM、模拟按键。
隔离：光耦、隔离电源、保险丝、浪涌保护、漏电保护。
本地控制：物理开关、急停、手动接管按钮。
日志：命令来源、执行结果、失败原因。
```

## 五级接入模型

### Level 0：只观察

只加传感器，不加控制。

适合：

- 燃气灶。
- 配电箱。
- 医疗设备。
- 冰箱。
- 鱼缸氧气泵。
- 重要网络设备。

可加传感器：

- 电流传感器。
- 温度传感器。
- 门磁。
- 水浸传感器。
- 烟雾/燃气传感器。
- 摄像头或视觉模型。

### Level 1：非侵入控制

不拆机，通过原有外部控制方式接入。

适合：

- 空调。
- 电视。
- 投影仪。
- 风扇。
- 音响。
- 扫地机器人。

方式：

- 红外遥控。
- 蓝牙控制。
- Wi-Fi 局域网 API。
- 机械按键器。

缺点是状态反馈可能不完整，应配合功耗、温度、照度等传感器验证。

### Level 2：电源级控制

通过智能插座、继电器或接触器控制电源。

适合：

- 台灯。
- 简单风扇。
- 普通加湿器。
- 鱼缸灯。
- 部分低风险小电器。

不适合：

- 冰箱。
- 洗衣机。
- 空调压缩机。
- NAS 或电脑。
- 热水器。
- 电饭煲、烤箱、微波炉。
- 医疗设备。

电源级控制应更多作为保护和状态感知手段，而不是所有设备的日常控制方式。

### Level 3：低压接口接入

只接入低压控制信号，不碰高压功率部分。

常见接口：

- UART。
- I2C。
- SPI。
- GPIO。
- PWM。
- 干接点。
- 0-10V。
- RS485。
- CAN。
- Modbus。

适合：

- 中央空调。
- 新风。
- 地暖。
- 电动窗帘。
- 车库门。
- 水泵系统。
- 暖通设备。

这是传统家电接入 home agent 的理想工程路线。

### Level 4：替换控制板

保留机械和功率结构，替换原厂控制板。

风险很高，因为原厂控制板包含大量安全逻辑：

- 过温保护。
- 过流保护。
- 电机堵转保护。
- 水位检测。
- 门锁检测。
- 压缩机延时保护。
- 防干烧。
- 防溢水。
- 传感器故障处理。
- 认证和电磁兼容设计。

此等级只适合专业人员、实验设备和低风险 DIY 场景。

### Level 5：原生 AI 家电

未来家电出厂时就应暴露标准能力和安全策略：

```json
{
  "id": "washer_01",
  "type": "washing_machine",
  "location": "balcony",
  "capabilities": ["start", "pause", "set_program", "read_status"],
  "safety": {
    "requires_door_locked": true,
    "requires_no_water_leak": true,
    "manual_override": true
  }
}
```

## 设备改造建议

| 设备 | 推荐等级 | 说明 |
|---|---|---|
| 灯光 | Level 1-3 | 低风险，适合高度自动化 |
| 窗帘 | Level 1-3 | 需要限位和夹手保护 |
| 空调 | Level 1 或 3 | 避免频繁断电，保留压缩机保护 |
| 新风/地暖 | Level 3 | 适合标准总线接入 |
| 电视/音响 | Level 1 | HDMI-CEC、红外、局域网 API |
| 扫地机器人 | Level 1 | 注意夜间噪音和地面风险 |
| 洗衣机 | Level 0-1 | 可预约和提醒，启动需条件检查 |
| 冰箱 | Level 0 | 主要观察温度、门磁、功耗 |
| 厨房加热设备 | Level 0-1 | 加热和点火必须谨慎 |
| 门锁 | Level 0-1 | 开门动作必须强认证 |
| 燃气阀 | Level 0 | 可异常关闭，不应自动打开 |
| 配电箱 | Level 0 | 主要监测，控制需专业系统 |

## 最重要的边界

home agent 不是让 AI 强行接线控制一切，而是让每个设备变成一个可被安全编排的节点。

每个节点至少应具备：

- 身份。
- 能力描述。
- 状态回读。
- 风险等级。
- 本地安全规则。
- 隔离控制。
- 手动接管。
- 审计日志。
